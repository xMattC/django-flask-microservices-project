# Roadmap

## Overview

The project is developed in phases, each representing a functional milestone.

---

## Phase 1 — Planning & Foundation

- Define product vision and architecture
- Set up repository structure
- Scaffold Django web service
- Configure CI workflows

---

## Phase 2 — Identity & Web

- User authentication
- Login / logout functionality
- Protected routes
- Django as BFF layer

---

## Phase 3 — Projects

- Projects service (Flask)
- Project CRUD
- Integration with Django

---

## Phase 4 — Time Tracking

- Clock-in / clock-out
- Time entry management
- Prevent overlapping sessions

---

## Phase 5 — Initial Deployment

- Deploy working system
- Configure CI/CD pipeline
- Add health checks and verification

---

## Phase 6 — Tasks

- Task service
- Task status tracking
- Project-task relationships

---

## Phase 7 — Metrics

- Metrics service (FastAPI)
- Aggregated reporting
- Time summaries

---

## Phase 8 — Subscriptions

- Trial system
- Subscription management
- Feature gating

---

## Phase 9 — Testing & Docs

- Expand test coverage
- Improve documentation
- Finalise architecture

---

## Phase 10 — React Frontend

- Introduce React client
- Replace Django-rendered views
- Fully decoupled frontend
